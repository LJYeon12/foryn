# PRD: Foryn 지원 서버

Foryn은 Mori / Foryn 계열의 ADHD·정서·복약 지원 모바일 서비스다. 이 문서는 사용자가 받아야 할 결과와 제품 범위를 정의한다. 구현 경계는 [아키텍처](ARCHITECTURE.md), 결정 근거는 [ADR](ADR.md)을 따른다.

구현된 동작은 [기능별 설명](README.md#기능별-설명)과 코드·테스트로 확인한다. 현재 실행 환경은 [아키텍처](ARCHITECTURE.md#실행-환경과-외부-연동)를 따른다.

## 1. 목표
- ADHD·정서 관리 사용자가 모바일 앱에서 대화, 복약 기록, 알림, 구독 상태를 안정적으로 사용할 수 있는 백엔드 API를 제공한다.
- 사용자의 민감한 건강·정서 데이터를 다루므로 기능 속도보다 인증, 개인정보 보호, 재시도 가능성, 관측 가능성을 우선한다.

## 2. 사용자
- 최종 사용자: Apple 로그인으로 앱을 사용하고, 챗봇 대화와 복약 루틴을 기록하는 사람.
- 운영자: 장애·배포·데이터 보정 대응을 혼자 수행할 수 있어야 하는 서버 운영자.
- 운영 응답: 야간 자동 복구를 전제로 하지 않고 안전한 실패, 명확한 재시도와 관측을 제공한다.
- 앱 클라이언트: `/api/v1/*` JSON API와 push token 등록 API를 호출하는 모바일 앱.

## 3. 핵심 기능
1. Apple 로그인, JWT 발급·재발급·로그아웃, access token blacklist.
2. 챗봇 세션 생성, 메시지 저장, 최근 24시간 이력 조회, 행동기술 기반 응답 생성.
3. 사용자 프로필, 닉네임, 계정 초기화·삭제.
4. 복약 계획 생성·수정·삭제, 복약 기록 저장, 주간·월간 리포트.
5. 오늘·과거 선택 날짜의 한줄일기 초안 생성·갱신·완료·조회, 공감 코멘트와 태그 기록.
6. FCM device token 등록, 복약 알림과 한줄일기 알림 설정·예약·발송.
7. 월간 감정 리포트에 완료 일기 점수의 2배 가중치 반영, 최근 이틀 태그 요약과 당일 캐시.
8. Apple App Store 구독 검증, 서버 알림 처리, 구독 상태 조회.
9. Sentry, Actuator, Prometheus 연동 코드와 지표. 실제 관측 환경은 별도 구성.

## 4. MVP 포함 기준
- 인증이 없는 사용자 데이터 접근은 차단한다.
- 복약 알림은 중복 가능성을 견디되 누락과 무한 재시도를 방지한다.
- 결제 상태는 클라이언트 입력이 아니라 Apple 검증 결과와 서버 DB로 판단한다.
- 챗봇 응답은 정서 지원 범위에 머물며 진단·처방·복용 변경을 지시하지 않는다.
- 한줄일기는 선택 날짜별 `DRAFT + COMPLETED` 합계가 최대 3개이며, 완료는 같은 기록의 상태 전환으로 처리한다.
- 주간·월간 감정 리포트의 자료와 빈 값 정책을 구분한다. 일기는 월간에만 포함하고, 요약은 조회일 기준 최근 이틀을 사용한다.

## 5. MVP 제외 사항
- 실시간 WebSocket/streaming 챗봇.
- 관리자 콘솔 기반 수동 결제 보정.
- 다국어 locale 최적화와 모든 기능에 걸친 사용자별 timezone 통일. 일기·월간 감정·일기 알림은 저장된 사용자 시간대를 사용하지만 주간 리포트와 복약은 다른 기준이 남아 있다.
- 의료기관 연동, EMR 연동, 의사·상담사 워크플로.
- 자동 canary 분석과 완전 자동 rollback.

## 6. 성공 기준
- PR 변경은 관련 테스트와 `./gradlew test`를 통과한다.
- 구조 변경은 `./gradlew archTest`, 정적 규칙 변경은 `./gradlew lint`를 통과한다.
- 운영 배포를 새로 연결할 때에는 해당 환경의 단계적 배포와 rollback 검증을 정의한다. 현재 저장소에는 운영 배포와 metadata 렌더 검증 도구가 없다.
- 민감값은 로그, Sentry, 문서, fixture에 원문으로 남지 않는다.

## 7. 제품 리스크
- 인증·구독 버그는 권한 오남용으로 이어진다.
- 알림 중복은 신뢰 하락, 알림 누락은 핵심 루틴 실패로 이어진다.
- LLM 비용·latency 계측 없이 context를 늘리면 운영비와 장애 원인이 숨는다.
- 건강 관련 문구가 의료 조언처럼 보이면 제품 안전 리스크가 된다.
